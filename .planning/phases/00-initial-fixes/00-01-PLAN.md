  <files>.zshrc</files>
  <action>
Add XDG Base Directory exports at the VERY TOP of .zshrc (before the existing Pyenv section):

```bash
# XDG Base Directory Specification
# Must be set before any tool initialization
export XDG_CONFIG_HOME="${XDG_CONFIG_HOME:-$HOME/.config}"
export XDG_DATA_HOME="${XDG_DATA_HOME:-$HOME/.local/share}"
export XDG_CACHE_HOME="${XDG_CACHE_HOME:-$HOME/.cache}"
export XDG_STATE_HOME="${XDG_STATE_HOME:-$HOME/.local/state}"

# Ensure directories exist
mkdir -p "$XDG_CONFIG_HOME" "$XDG_DATA_HOME" "$XDG_CACHE_HOME" "$XDG_STATE_HOME"
```

Key points:
- Use `${VAR:-default}` syntax to respect existing values
- Place BEFORE Pyenv, oh-my-zsh, and all other initializations
- Include mkdir to ensure directories exist
- Add comment explaining why placement matters
