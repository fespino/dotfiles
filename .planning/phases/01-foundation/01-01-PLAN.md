**Key Implementation Details:**

OS Detection (BOOT-02):
```bash
detect_os() {
    case "$(uname -s)" in
        Darwin) echo "macos" ;;
        Linux)  echo "linux" ;;
        *)      echo "unknown" ;;
    esac
}
```
Display detected OS at start of run.

Dry-Run Mode (BOOT-04):
```bash
execute() {
    if [[ "$DRY_RUN" == true ]]; then
        info "[dry-run] $*"
    else
        "$@"
    fi
}
```
Wrap all file operations (mkdir, mv, ln) with execute function.

Backup (BOOT-03, from CONTEXT.md):
- Store in ~/.dotfiles-backup/YYYYMMDD_HHMMSS/
- Preserve relative path structure in backup
- Create session dir on first backup only
- In dry-run: show what would be backed up

Safe Symlink (idempotency):
1. If already correct symlink: skip with "already linked" message
2. If symlink pointing elsewhere: prompt user (from CONTEXT.md decision)
3. If regular file exists: backup first, then create symlink
4. Create parent directories as needed

Symlink Mappings (hardcoded per CONTEXT.md decision):
```bash
declare -A SYMLINKS=(
    ["${DOTFILES_DIR}/.zshrc"]="${HOME}/.zshrc"
    ["${DOTFILES_DIR}/kitty"]="${XDG_CONFIG_HOME:-$HOME/.config}/kitty"
    ["${DOTFILES_DIR}/tmux/tmux.conf"]="${HOME}/.tmux.conf"
    ["${DOTFILES_DIR}/vim"]="${HOME}/.vim"
    ["${DOTFILES_DIR}/bin/cht.sh"]="${HOME}/.local/bin/cht.sh"
)
```

Color Output (from CONTEXT.md):
- Auto-detect TTY with `[[ -t 1 ]]`
- Symbols when TTY: checkmark, x, arrow
- ASCII fallback when piped: [OK], [FAIL], ->
- Colors: green for success, red for error, yellow for info

Help Text:

Set up dotfiles by creating symlinks from this repository to your home directory.

    -n, --dry-run   Preview changes without making them

Examples:
